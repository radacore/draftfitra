0. Apa yang akan kita hitung?

Bayangkan kita punya catatan 8 pasien MDR-TB. Dari catatan itu, kita ingin menebak: apakah pengobatan seorang pasien akan Berhasil atau Tidak Berhasil?

Komputer melakukan ini dengan dua cara, dan kita akan menghitungnya dengan tangan:

  1. SMOTE — membuat “pasien buatan” baru supaya jumlah kedua kelompok seimbang.
  2. Random Forest — banyak pohon keputusan yang masing-masing “memilih”, lalu dipilih suara terbanyak.

Setelah itu kita nilai seberapa tepat tebakannya.

3. Menghitung jarak antara dua pasien

SMOTE butuh tahu pasien mana yang “mirip”. Kami mengukur kemiripan dengan jarak: makin kecil jaraknya, makin mirip. Rumusnya (jarak Euclidean):

Jarak = √( (Usia₁ − Usia₂)² + (Kepatuhan₁ − Kepatuhan₂)² + (BB₁ − BB₂)² )

Contoh: jarak antara P6 dan P7.

Usia : (45 − 60)² = (−15)² = 225 Kepatuhan : (0 − 0)² = 0² = 0 Berat : (60 − 65)² = (−5)² = 25 Jumlah = 225 + 0 + 25 = 250 Jarak = √250 ≈ 15,81

Semua jarak antar pasien “Tidak Berhasil” (P6, P7, P8):

4. SMOTE: membuat pasien baru

SMOTE membuat pasien baru di antara dua pasien “Tidak Berhasil” yang mirip. Pasien baru diletakkan di tengah-tengah (atau di sepanjang garis penghubungnya). Rumusnya:

Pasien baru = X + λ × (X_tetangga − X) X = pasien asal, X_tetangga = pasien mirip, λ (lambda) = angka acak antara 0 dan 1. Di sini kita pakai λ = 0,5 (tengah-tengah).

Pasien baru #1 (antara P6 dan P7)

Usia : 45 + 0,5 × (60 − 45) = 45 + 0,5 × 15 = 45 + 7,5 = 52,5 Kepatuhan : 0 + 0,5 × (0 − 0) = 0 + 0 = 0 Berat : 60 + 0,5 × (65 − 60) = 60 + 0,5 × 5 = 60 + 2,5 = 62,5 ➜ Pasien baru #1 = (52,5 ; 0 ; 62,5) Hasil = Tidak Berhasil

Pasien baru #2 (antara P7 dan P8)

Usia : 60 + 0,5 × (35 − 60) = 60 + 0,5 × (−25) = 60 − 12,5 = 47,5 Kepatuhan : 0 + 0,5 × (0 − 0) = 0 Berat : 65 + 0,5 × (70 − 65) = 65 + 2,5 = 67,5 ➜ Pasien baru #2 = (47,5 ; 0 ; 67,5) Hasil = Tidak Berhasil

5. Mencari pertanyaan terbaik (indeks Gini)

Pohon keputusan bekerja seperti permainan tebak-tebakan. Ia mengajukan pertanyaan, misalnya “Apakah Kepatuhan = Patuh?” atau “Apakah Berat Badan ≤ 57,5?”. Untuk memilih pertanyaan terbaik, ia memakai indeks Gini: seberapa campur sebuah kelompok. Nilai 0 = benar-benar bersih, makin besar makin campur.

Gini = 1 − ( p₀ )² − ( p₁ )² p₀ = bagian anggota kelompok “Berhasil” (0) p₁ = bagian anggota kelompok “Tidak Berhasil” (1)

Langkah A — Gini sebelum bertanya (semua 10 data)

Ada 5 “Berhasil” dan 5 “Tidak Berhasil” dari 10 data: p₀ = 5/10 = 0,5 p₁ = 5/10 = 0,5 Gini = 1 − (0,5)² − (0,5)² = 1 − 0,25 − 0,25 = 0,5 (cukup campur)

Langkah B — Coba pertanyaan: “Kepatuhan ≤ 0,5?” (= Tidak Patuh)

Pertanyaan ini memecah data menjadi dua kelompok:

KIRI (Tidak Patuh) : P5, P6, P7, P8, S1, S2 → 6 data isi: 1 “Berhasil” + 5 “Tidak Berhasil” p₀ = 1/6 ≈ 0,167 p₁ = 5/6 ≈ 0,833 Gini = 1 − (0,167)² − (0,833)² = 1 − 0,0278 − 0,6944 = 0,2778 KANAN (Patuh) : P1, P2, P3, P4 → 4 data isi: semuanya “Berhasil” (bersih) Gini = 1 − (1)² − (0)² = 0 Gini gabungan = (bobot kiri × Gini kiri) + (bobot kanan × Gini kanan) = (6/10 × 0,2778) + (4/10 × 0) = 0,1667 + 0 = 0,1667

Karena 0,1667 jauh lebih kecil dari 0,5, pertanyaan “Kepatuhan ≤ 0,5?” adalah pertanyaan yang bagus, dan dipakai sebagai pertanyaan pertama pohon.

6. Menyusun pohon keputusan

Dengan pertanyaan-pertanyaan yang dipilih, kita gambar pohonnya. Kita buat 3 pohon supaya bisa saling menutupi kelemahan (itulah gunanya “hutan”). Tiap pohon memakai pertanyaan yang sedikit berbeda.

Pohon 1

Apakah Kepatuhan ≤ 0,5? (Tidak Patuh?) │ ├─ YA → Apakah Berat Badan ≤ 57,5? │ ├─ YA → Berhasil │ └─ TIDAK → Tidak Berhasil │ └─ TIDAK (Patuh) → Berhasil

Pohon 2

Apakah Berat Badan ≤ 57,5? │ ├─ YA → Berhasil │ └─ TIDAK → Apakah Usia ≤ 30? ├─ YA → Berhasil └─ TIDAK → Tidak Berhasil

Pohon 3

Apakah Berat Badan ≤ 57,5? │ ├─ YA → Berhasil │ └─ TIDAK → Apakah Kepatuhan ≤ 0,5? (Tidak Patuh?) ├─ YA → Tidak Berhasil └─ TIDAK (Patuh) → Berhasil
Cara membacanya: mulai dari atas, jawab tiap pertanyaan, ikuti cabangnya sampai ketemu jawaban akhir (Berhasil atau Tidak Berhasil).

7. Tiga pohon bersuara (voting)

Sekarang ada pasien baru: Usia 40, Kepatuhan Patuh (1), Berat Badan 60. Setiap pohon “menjawab”, lalu kita hitung suaranya.

PohonJalan pertanyaannyaSuara

Pohon 3 BB = 60 > 57,5 → Kepatuhan = 1 > 0,5 → Berhasil Berhasil (0)

Hasil akhir untuk pasien baru = Berhasil (menang 2 suara dari 3).

8. Menghitung keyakinan

Keyakinan = seberapa banyak pohon yang setuju dengan jawaban pemenang.

Keyakinan = (suara pemenang ÷ jumlah pohon) × 100% = (2 ÷ 3) × 100% = 0,6667 × 100% = 66,67%
Hasil
Sistem 66,67% yakin pasien tersebut akan Berhasil. Kalau ketiga pohon setuju (3 dari 3), keyakinannya = 100%.

Jumlah326
  • TP (True Positive) = 2 — “Tidak Berhasil” yang benar ditebak Tidak Berhasil.
  • TN (True Negative) = 3 — “Berhasil” yang benar ditebak Berhasil.
  • FP (False Positive) = 0 — “Berhasil” tapi salah ditebak Tidak Berhasil.
  • FN (False Negative) = 1 — “Tidak Berhasil” tapi salah ditebak Berhasil (paling berbahaya).

a. Akurasi — seberapa banyak tebakan yang benar

Akurasi = (TP + TN) ÷ seluruh data = (2 + 3) ÷ 6 = 5 ÷ 6 = 0,8333 = 83,33%

b. Presisi — dari yang ditebak “Tidak Berhasil”, berapa yang benar-benar begitu

Presisi = TP ÷ (TP + FP) = 2 ÷ (2 + 0) = 2 ÷ 2 = 1 = 100%

c. Recall — dari semua yang benar-benar “Tidak Berhasil”, berapa yang berhasil ditemukan

Recall = TP ÷ (TP + FN) = 2 ÷ (2 + 1) = 2 ÷ 3 = 0,6667 = 66,67%

d. F1-score — keseimbangan antara presisi dan recall

F1 = 2 × (Presisi × Recall) ÷ (Presisi + Recall) = 2 × (1 × 0,6667) ÷ (1 + 0,6667) = 1,3333 ÷ 1,6667 = 0,8 = 80%

10. Rangkuman

Beginilah alur lengkapnya dari awal sampai akhir:

  1. Data: 8 pasien (5 Berhasil, 3 Tidak Berhasil).
  2. Ubah kata jadi angka: Patuh=1, Tidak Patuh=0, Berhasil=0, Tidak Berhasil=1.
  3. Hitung jarak: cari pasien yang mirip (mis. P6–P8 jarak 14,14).
  4. SMOTE: buat 2 pasien buatan → jumlah jadi seimbang 5 : 5.
  5. Indeks Gini: pilih pertanyaan paling “bersih” (Gini 0,1667 < 0,5).
  6. Pohon: susun pohon dari pertanyaan-pertanyaan itu.
  7. Voting: 3 pohon memilih → suara terbanyak menang (Berhasil, 2 dari 3).
  8. Keyakinan: (2 ÷ 3) × 100% = 66,67%.
  9. Penilaian: akurasi 83,33%, presisi 100%, recall 66,67%, F1 80%.
Catatan: contoh ini memakai 3 pohon dan 3 ciri saja agar bisa dihitung dengan tangan. Model pada penelitian sebenarnya memakai lebih banyak data (175 baris), 17 variabel, dan 100 pohon — tetapi langkah-langkahnya persis sama seperti di atas, hanya diulang lebih banyak.
